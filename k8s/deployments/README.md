# Deployments

This directory contains Kubernetes Deployment resources for all application services.

## Files

1. `identity-deployment.yaml` - Identity service
2. `salary-deployment.yaml` - Salary submission service
3. `vote-deployment.yaml` - Vote service
4. `search-deployment.yaml` - Search service
5. `stats-deployment.yaml` - Stats service
6. `bff-deployment.yaml` - Backend-for-Frontend service
7. `frontend-deployment.yaml` - Frontend web application
